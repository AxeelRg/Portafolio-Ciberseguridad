
# 🛡️ Práctica 01 - Investigación de Brechas de Seguridad

## 📌 Introducción

Esta práctica representa el **inicio de mi portafolio profesional de ciberseguridad**.

A través de este repositorio documentaré mi progreso durante la formación como **Analista Junior en Ciberseguridad** en Cisco Networking Academy, registrando los conocimientos, habilidades y experiencias adquiridas en cada módulo.

---

# 🎯 Objetivo

Investigar diferentes casos reales de brechas de seguridad para comprender:

- Qué organizaciones fueron afectadas.
- Qué información fue comprometida.
- Qué técnicas utilizaron los atacantes.
- Qué medidas de seguridad pudieron prevenir estos incidentes.

---

# 🛠️ Actividades realizadas

Durante esta práctica investigué diferentes incidentes reales de ciberseguridad y documenté:

- Organización afectada.
- Fecha del incidente.
- Información comprometida.
- Tipo de ataque.
- Medidas preventivas.
- Fuente de consulta.
